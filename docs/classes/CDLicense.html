    activateLicense

    • activateLicense(
          license_string: string,
          qrlic?: boolean,
      ): Promise<LicenseResult | undefined>

      Activate the SDK license using an EDK license key.

      Parameters

      • license_string: string

        Valid EDK license key string from Cortex licensing system.

      • Optionalqrlic: boolean

        Optional QR license code flag (internal use).

      Returns Promise<LicenseResult | undefined>

      A promise resolving with LicenseResult object containing:

      • status: License status (ACTIVATED, TRIAL, EXPIRED, INVALID, etc.)
      • message: Human-readable status message
      • expirationDate: Formatted expiration date string (MM/DD/YYYY)
      • rawExpirationDate: JavaScript Date object for expiration

      Remarks

      CRITICAL: Must call init() on CDDecoder before calling this method. Activating a license enables all licensed symbologies and performance features. The method automatically:

      • Parses the license string
      • Validates license status (ACTIVATED, TRIAL, EXPIRED, etc.)
      • Enables/disables symbologies based on license
      • Enables performance features (multi-code, DPM, verification, etc.)
      • Initializes data collection if configured in license

      After activation, use getLicensedSymbologies() and getLicensedPerformanceFeatures() to query available capabilities.

      Throws

      Error - Thrown if license_string invalid, decoder not initialized, or license check fails.

      Since

      v1.0.0

      Example

      const decoder = new CDDecoder();
      await decoder.init();

      const license = new CDLicense();
      const result = await license.activateLicense('YOUR_EDK_LICENSE_KEY');

      if (result.status === license_status.ACTIVATED) {
        console.log('License activated successfully');
        console.log('Expires:', result.expirationDate);
        
        const symbologies = await license.getLicensedSymbologies();
        console.log('Licensed for:', symbologies);
      }

    checkLicense

    • checkLicense(): license_status

      Check the current license activation status.

      Returns license_status

      license_status enum value indicating current state.

      Remarks

      Returns the license_status enum indicating current state:

      • ACTIVATED: License valid and active
      • TRIAL: Trial license in use
      • EXPIRED: License has expired
      • INVALID: Invalid license key
      • TEMPORARY_ACTIVATED: Temporary license activation
      • REVOKED: License has been revoked
      • UNKNOWN: Status unknown (typically before activation attempt)

      Call activateLicense() before checking for ACTIVATED status.

      Since

      v1.0.0

      Example

      const status = license.checkLicense();

      if (status === license_status.ACTIVATED) {
        console.log('License is active and valid');
      } else if (status === license_status.EXPIRED) {
        console.log('License has expired');
      } else if (status === license_status.INVALID) {
        console.log('Invalid license key');
      }

      See

      • activateLicense to activate license and enable decoding
      • license_status enum for all possible states

    getLicensedExtendedSymbologies

    • getLicensedExtendedSymbologies(): Promise<string[]>

      Get extended/special symbologies enabled by the current license.

      Returns Promise<string[]>

      A promise resolving with array of extended symbology names (strings). Empty array if license not activated.

      Remarks

      Extended symbologies include postal codes (USPS, Royal Mail, Australia Post, etc.) and GS1 DataBar variants (DB_14, DB_LIMITED, DB_EXPANDED, etc.). Also includes special variants like MicroPDF417, QR_MICRO, QR_MODEL1, etc.

      Use with getLicensedSymbologies() to get complete capability list. Returns empty array if license not activated.

      Since

      v1.0.0

      Example

      await license.activateLicense(licenseKey);
      const extended = await license.getLicensedExtendedSymbologies();

      extended.forEach(sym => {
        console.log('Extended enabled:', sym); // e.g., "USPS_Postnet", "DB_EXPANDED"
      });

      • activateLicense to activate license first
      • getLicensedSymbologies for standard symbologies

    getLicensedPerformanceFeatures

    • getLicensedPerformanceFeatures(): Promise<CDPerformanceType[]>

      Get the advanced features enabled by the current license.

      Returns Promise<CDPerformanceType[]>

      A promise resolving with array of CDPerformanceType enum values. Empty array if license not activated.

      Remarks

      Performance features include:

      • MULTI_CODE: Decode multiple barcodes per frame (license limit: 20 or 128)
      • DPM: Direct Part Marking support (dotpeen, laser, chemical etch)
      • VERIFICATION: Quality metrics (ISO15415, AIMDPM grades and scores)
      • DATA_COLLECTION: Automatic decode data transmission to server

      Returns empty array if license not activated.

      Since

      v1.0.0

      Example

      await license.activateLicense(licenseKey);
      const features = await license.getLicensedPerformanceFeatures();

      if (features.includes(CDPerformanceType.MULTI_CODE)) {
        console.log('Multi-code decoding enabled');
        await decoder.setBarcodesToDecode(5, false); // Decode up to 5 codes
      }

      if (features.includes(CDPerformanceType.VERIFICATION)) {
        console.log('Quality verification enabled');
      }

    getLicensedSymbologies

    • getLicensedSymbologies(): Promise<string[]>

      Get the list of barcode symbologies enabled by the current license.

      Returns Promise<string[]>

      A promise resolving with array of symbology names (strings) enabled by license. Empty array if license not activated.

      Remarks

      IMPORTANT: This method reflects only licensed STANDARD symbologies (1D and 2D codes). Use getLicensedExtendedSymbologies() to get special postal/GS1 variants. Returns empty array if license not activated.

      Common symbologies include: Code128, Code39, EAN13, UPC-A, DataMatrix, QR, PDF417, Aztec, etc.

      Since

      v1.0.0

      Example

      await license.activateLicense(licenseKey);
      const symbologies = await license.getLicensedSymbologies();

      symbologies.forEach(sym => {
        console.log('Enabled:', sym); // e.g., "Code128", "DataMatrix", "QR"
      });

      • getLicensedExtendedSymbologies for postal/GS1 variants
      • getLicensedPerformanceFeatures to get enabled features

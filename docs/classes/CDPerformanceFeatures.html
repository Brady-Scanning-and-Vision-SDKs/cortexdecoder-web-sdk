    • set DPMMode(dpm: CDDPM): void

      Set Direct Part Marking (DPM) decoding mode.

      Parameters

      • dpm: CDDPM

        CDDPM enum value specifying DPM mode.

      Returns void

      Remarks

      DPM enables decoding of barcodes marked directly on parts/components:

      • DISABLE: No DPM processing (standard barcode mode)
      • DOTPEEN_DARK_ON_LIGHT: Dots on light surface (common for metals)
      • DOTPEEN_LIGHT_ON_DARK: Dots on dark surface
      • LASER_CHEM_ETCH: Laser or chemical etched marks

      DPM codes are typically lower quality and harder to read. Enabling DPM increases CPU usage and may impact standard barcode recognition. Requires DPM performance feature license.

      Since

      v1.0.0

      Example

      // Enable for dotpeen dark-on-light (typical manufacturing)
      performanceFeatures.DPMMode = CDDPM.DOTPEEN_DARK_ON_LIGHT;

      // Enable for laser-etched marks
      performanceFeatures.DPMMode = CDDPM.LASER_CHEM_ETCH;

      // Disable DPM
      performanceFeatures.DPMMode = CDDPM.DISABLE;

      See

      • DPMMode getter to check current mode

    • set verification(type: CDVerifier): void

      Enable barcode quality verification and include metrics in results.

      Parameters

      • type: CDVerifier

        CDVerifier enum value specifying verification standard.

      Returns void

      Remarks

      Verification measures barcode quality according to international standards:

      • DISABLE: No verification (default)
      • ISO15415: ISO 15415 quality grades for 2D codes (DataMatrix, QR, PDF417, Aztec, etc.)
      • AIMDPM: AIM DPM grading for Direct Part Marked codes

      When enabled, CDResult includes verification object with grades and scores:

      • Grades: A-F scale for contrast, reflectance, modulation, etc.
      • Scores: Numeric scores for detailed analysis
      • Metrics: Aperture size, uniformity, damage assessment

      Verification increases CPU usage (~10-15% overhead). Requires verification performance feature license.

      Since

      v1.0.0

      Example

      // Enable ISO 15415 verification for 2D codes
      performanceFeatures.verification = CDVerifier.ISO15415;

      // Enable AIM DPM verification for marked parts
      performanceFeatures.verification = CDVerifier.AIMDPM;

      // Disable verification
      performanceFeatures.verification = CDVerifier.DISABLE;

      // After decoding with verification enabled:
      const results = await decoder.decode(image);
      results.forEach(result => {
        console.log('Grade:', result.verification.gradeFinal); // A-F
        console.log('Contrast:', result.verification.gradeContrast);
      });

      • verification getter to check current setting
      • CDVerifier enum for available options
      • CDResult for verification data structure

    setDataParsing

    • setDataParsing(parsing: CDDataParsing, configString: string): Promise<void>

      Set data parsing mode with optional configuration string.

      Parameters

      • parsing: CDDataParsing

        CDDataParsing enum value specifying parsing mode.

      • configString: string

        Configuration string for parsing rules (empty for defaults).

      Returns Promise<void>

      A promise that resolves when parsing is configured.

      Remarks

      Data parsing automatically extracts and formats specific data from decoded barcodes:

      • DL_PARSING: Driver License parsing (North American format)
      • GS1_PARSING: GS1 element string parsing and separation
      • UDI_PARSING: Unique Device Identifier (medical/pharma)
      • ISO_PARSING: ISO data element parsing
      • STR_MATCH_REPLACE: Pattern matching and string replacement
      • DISABLE: No parsing (raw barcode data)

      Configuration strings define parsing rules/patterns. Leave empty for defaults. Requires performance feature license on activated license.

      Since

      v1.0.0

      Example

      // Enable Driver License parsing
      await performanceFeatures.setDataParsing(CDDataParsing.DL_PARSING, "");

      // Enable GS1 parsing with custom config
      await performanceFeatures.setDataParsing(
        CDDataParsing.GS1_PARSING,
        "{...custom GS1 config...}"
      );

      // Disable parsing
      await performanceFeatures.setDataParsing(CDDataParsing.DISABLE, "");

      • getDataParsing to get current parsing mode
      • getConfigStringForDataParsing to get config string
      • CDDataParsing enum for available modes

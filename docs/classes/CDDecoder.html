    • set characterSetEncoding(value: CDCharacterEncoding): void

      Set character encoding for barcode data interpretation.

      Parameters

      • value: CDCharacterEncoding

        CDCharacterEncoding enum value.

      Returns void

      Remarks

      Defines how barcode bytes are interpreted as text characters. UTF-8 is standard. Other encodings (ISO-8859-1, Shift-JIS, etc.) support international characters. Only applies if the selected encoding is supported by iconv-lite. UNDEF uses raw barcode data without conversion.

      Since

      v1.0.0

      Example

      decoder.characterSetEncoding = CDCharacterEncoding.UTF8;       // Standard
      decoder.characterSetEncoding = CDCharacterEncoding.ISO_8859_1; // Western European
      decoder.characterSetEncoding = CDCharacterEncoding.SHIFT_JIS;  // Japanese

    • set multiFrameDecoding(enable: boolean): void

      Enable multi-frame decoding by accumulating results across frames.

      Parameters

      • enable: boolean

        true to accumulate across frames, false for single frame mode.

      Returns void

      Remarks

      IMPORTANT: setBarcodesToDecode() must be called first with count > 0. When enabled, decoder collects barcodes across multiple frames, accumulating results until the specified count is reached. Useful when single frame doesn't contain all barcodes. Disabling returns to single-frame mode.

      Throws

      Error - Thrown if barcodesToDecode count not set first.

      Since

      v1.0.0

      Example

      await decoder.setBarcodesToDecode(5, false);
      decoder.multiFrameDecoding = true;  // Accumulate 5 barcodes across frames
      decoder.multiFrameDecoding = false; // Back to single frame

    decode

    • decode(
          image: DecodeMethodInput,
          previewWidth?: number,
          previewHeight?: number,
      ): Promise<CDResult[]>

      Decode a single image for barcodes.

      Parameters

      • image: DecodeMethodInput

        Image source: HTMLImageElement, HTMLVideoElement, HTMLCanvasElement, Blob, ImageData, ImageBitmap, or OffscreenCanvas.

      • OptionalpreviewWidth: number

        Optional preview/display width (helps with coordinate scaling).

      • OptionalpreviewHeight: number

        Optional preview/display height (helps with coordinate scaling).

      Returns Promise<CDResult[]>

      A promise resolving with array of CDResult objects, one per decoded barcode.

      Remarks

      Critical: Must call init() before first decode(). License must be active. Supports multiple image sources and applies all configured decoder settings. Returns CDResult array with barcode data, coordinates, symbology, and decode time. Quality metrics (verification) included if enabled.

      Throws

      Error - Thrown if decoding fails or decoder not initialized.

      Since

      v1.0.0

      Example

      const imageElement = document.getElementById('barcode') as HTMLImageElement;
      const results = await decoder.decode(imageElement, 640, 480);

      results.forEach(result => {
        if (result.status === CDDecodeStatus.SUCCESS) {
          console.log('Barcode:', result.barcodeData);
          console.log('Type:', result.symbology);
          console.log('Time:', result.decodeTime + 'ms');
        }
      });

    setBarcodesToDecode

    • setBarcodesToDecode(value: number, exactMatch: boolean): Promise<number>

      Set the number of barcodes to decode per image/frame.

      Parameters

      • value: number

        Number of barcodes to decode. 0 = unlimited (within license limits). Must be >= 0.

      • exactMatch: boolean

        If true, decoder must find exactly 'value' codes. If false, decodes up to 'value' codes.

      Returns Promise<number>

      A promise that resolves with the effective barcode limit.

      Remarks

      Important: Setting value = 0 enables unlimited decoding up to license limits (128 with multi-code license, 20 otherwise). When exactMatch = true, the decoder must decode exactly the specified number of codes. When exactMatch = false with value > 0, decoder decodes up to that maximum but can return fewer.

      Enabling multi-barcode decoding automatically adjusts the time limit multiplier.

      Throws

      Error - Thrown if value is not a number.

      Since

      v1.0.0

      Example

      // Decode up to 5 barcodes per image
      await decoder.setBarcodesToDecode(5, false);

      // Decode exactly 3 barcodes (fail if not found)
      await decoder.setBarcodesToDecode(3, true);

      // Unlimited barcodes (up to license limits)
      await decoder.setBarcodesToDecode(0, false);

    setRegionOfInterest

    • setRegionOfInterest(ROI: CDRect, ensureCorners: boolean): Promise<void>

      Restrict barcode search to a specific rectangular region.

      Parameters

      • ROI: CDRect

        CDRect object defining region corners (TopLeft, TopRight, BottomLeft, BottomRight).

      • ensureCorners: boolean

        If true, barcode must be completely within region. If false, partial barcodes allowed.

      Returns Promise<void>

      A promise that resolves when ROI is set.

      Remarks

      Limits decoder to search only within defined region, improving performance and reducing false positives. Coordinates are in preview coordinates (matching display/camera preview space). When ensureCorners=true, entire barcode must be within region; when false, partial barcodes are decoded.

      Throws

      Error - Thrown if ROI is not a CDRect instance.

      Since

      v1.0.0

      Example

      const roi = new CDRect();
      roi.TopLeft.X = 100;
      roi.TopLeft.Y = 100;
      roi.BottomRight.X = 400;
      roi.BottomRight.Y = 300;
      await decoder.setRegionOfInterest(roi, true); // Entire barcode in region

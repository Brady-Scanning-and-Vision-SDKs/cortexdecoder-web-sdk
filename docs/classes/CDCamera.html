    setCameraPosition

    • setCameraPosition(value: CDPosition, autoSwitch: boolean): Promise<void>

      Set the camera orientation (front or back) with optional automatic camera switching.

      Parameters

      • value: CDPosition

        Camera position from CDPosition enum (FRONT, BACK, or BACK_ULTRA_WIDE)

      • autoSwitch: boolean

        Enable automatic camera switching based on image quality detection

      Returns Promise<void>

      A promise that resolves when camera position is set.

      Remarks

      IMPORTANT: This operation internally stops the camera. The method intelligently detects and selects the best back camera based on device capabilities (supports iPhone Pro triple cameras and Android camera2 APIs). Auto-switch mode enables automatic switching between cameras based on image blurriness detection.

      Throws

      Error - Thrown if no back cameras found or invalid position specified.

      Since

      v1.0.0

      Example

      // Set to back camera with auto-switch enabled
      await camera.setCameraPosition(CDPosition.BACK, true);

      // Set to ultra-wide back camera without auto-switch
      await camera.setCameraPosition(CDPosition.BACK_ULTRA_WIDE, false);

      See

      getCameraPosition to get current camera orientation

    startPreview

    • startPreview(getResult: (arg0: CDResult[]) => any): Promise<void>

      Start video preview with barcode detection and return decoded results.

      Parameters

      • getResult: (arg0: CDResult[]) => any

        Callback function called for each decoded frame with array of CDResult

      Returns Promise<void>

      A promise that resolves when preview loop begins.

      Remarks

      CRITICAL PERFORMANCE NOTE: This is CPU-intensive and processes every video frame. Decoding results are passed to the callback function for each frame. Supports multiple rendering paths: MediaStreamTrackProcessor (Chrome/Edge), OffscreenCanvas (Firefox), and fallback Canvas for older browsers. On unsupported browsers, automatic camera switching based on image blur detection is available.

      Throws

      Error - Thrown if camera not started or video element not found.

      Since

      v1.0.0

      Example

      await camera.startPreview((results) => {
        results.forEach(result => {
          if (result.status === 0) { // Success
            console.log('Decoded:', result.barcodeData);
          }
        });
      });

      See

      • stopPreview to pause preview
      • CDResult for result structure
